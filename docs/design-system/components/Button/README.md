Botões de ação do painel e do telão.

- `qz-btn--primary`: uma ação principal por tela (Iniciar partida, Salvar quiz). Laranja com `shadow-press`.
- `qz-btn--secondary`: ações de apoio sobre `surface`.
- `qz-btn--ghost`: ações leves (Duplicar, Cancelar).
- `qz-btn--stage`: botão branco sobre o fundo `stage` do telão (Próxima pergunta, Mostrar ranking).
- Desabilitado: 45% de opacidade, sem sombra, com texto que explique o motivo (Aguardando jogadores).

Altura mínima de 48px para toque.
